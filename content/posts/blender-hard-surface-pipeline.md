## 硬表面建模的核心不是“细节多”

硬表面（hard surface）指的是以人工制品为主的建模对象：机械零件、武器、载具、工业设备。它的难点通常不在雕刻，而在**比例、倒角与拓扑**这三件事。

一个细节很多但比例错误的模型，导出到引擎后依然会显得廉价；反过来，比例准确、倒角干净的低模，即使面数不高，也能靠法线和材质撑住画面。

下面是一条可以复用的七阶段管线。它适用于 Blender，也可以平移到其他 DCC 软件。

## 七个阶段与交付物

| 阶段 | 目标 | 交付物 |
| --- | --- | --- |
| 1. Blockout | 锁定比例和体块关系 | 粗模、尺寸标注 |
| 2. Mid-poly | 确定主要结构 | 可编辑的中模 |
| 3. High-poly | 补倒角和细节 | 高模 |
| 4. Retopo | 得到干净的低模 | 游戏用低模 |
| 5. UV | 展开不重叠的 UV | UV 布局图 |
| 6. Bake | 把高模细节烘到低模 | Normal/AO/Curvature |
| 7. Material | 建立 PBR 材质 | 贴图组与材质 |

### 1. Blockout：先量后做

用一个立方体当比例尺，把对象拆成几个主形体。此阶段不要加倒角，不要做螺丝，不要急着卡线。判断标准只有一个：**从三个视角看，轮廓是否成立**。

建议在场景里放一个 1.8 m 的人形参考，或者直接按真实尺寸建模。单位混乱是后期材质和物理表现失真的常见原因。

### 2. Mid-poly：结构清楚，面数克制

把主形体用布尔、挤出、内插做出来。此时可以开始处理：

- 大孔洞与开口
- 面板分缝
- 主要凸起与凹槽
- 需要活动的部件（扳机、护木、关节）

保持四边面为主，允许少量三角面，但不要留下长条 n-gon。它们会在细分和烘焙时制造麻烦。

### 3. High-poly：倒角决定质感

硬表面的“重量感”主要来自倒角宽度。现实中的零件没有绝对锋利的边，哪怕 0.2 mm 的倒角，也会在光线下形成高光。

常用组合：

- **Bevel Modifier**：宽度 0.5–2 mm，段数 2–3，配合 `Clamp Overlap`。
- **Weighted Normal**：修正大面积平面上的法线，避免平滑后出现脏边。
- **Shade Auto Smooth**：按角度拆分平滑组，保留结构边。

不要在低模上直接堆高模细节。高模只负责“长什么样”，低模负责“怎么跑”。

### 4. Retopo：低模要经得起动画和引擎

游戏低模的目标不是复制高模，而是用尽量少的面承载轮廓和 UV。常用做法：

- 用高模重新拓扑，或从 mid-poly 清理。
- 结构线跟随倒角走向，避免在平面上出现无意义斜线。
- 需要形变的位置留出循环边。
- 对称部件只做一半，再用 Mirror 修改器。

检查面数时，按“屏幕占比”分配预算：主角武器可以 3–5 万三角面，背景道具几千面就够。

### 5. UV：先保证不重叠，再谈利用率

硬表面 UV 的优先级：

1. 所有面必须有唯一 UV，不能重叠（除非明确做贴图复用）。
2. 接缝藏在结构缝、背面或不易观察的位置。
3. 保持 texel density 一致，避免近景糊、远景浪费。
4. 为烘焙留出足够的边距（padding）。

Blender 里可以用 `Smart UV Project` 起步，但最终布局通常要手动整理。UV 方块尽量对齐，方便后期在 Substance Painter 或 Blender 里画磨损。

### 6. Bake：高低模之间的桥

烘焙的本质是把高模的表面信息投影到低模。关键设置：

- **Cage / Extrusion**：包住高低模之间的差异，避免漏烘。
- **Ray Distance**：太小会丢细节，太大会串到其他部件。
- **Margin**：至少 4–8 像素，防止接缝处出现黑边。
- **Normal Space**：游戏引擎通常用切线空间法线，注意 Y 轴方向（OpenGL / DirectX）。

常见问题排查：

| 现象 | 可能原因 |
| --- | --- |
| 接缝黑边 | UV 边距不足或法线空间不匹配 |
| 细节错位 | 高低模没有对齐，或 Cage 穿模 |
| 表面脏 | 低模法线未统一，或平滑组错误 |
| AO 有噪点 | 采样不足或高模有重叠面 |

### 7. Material：把故事放进贴图

一套基础 PBR 贴图至少包含：

- Base Color：固有色，不包含光照。
- Roughness：决定高光锐利程度。
- Metallic：金属为 1，非金属为 0，避免中间值滥用。
- Normal：切线空间法线。
- AO：环境遮蔽，按引擎需求决定是否使用。

磨损逻辑要符合物理：边缘先掉漆，凹槽积灰，手握区域更光滑。不要用一张噪声图全局叠加，那会让所有位置看起来一样旧。

## 导出前的检查清单

- 应用缩放与旋转，确认单位是米。
- 检查法线方向，删除多余顶点组和形态键。
- 合并同名材质，确认贴图路径为相对路径。
- 低模命名与引擎规范一致，例如 `SM_Part_01`。
- 导出 FBX 或 glTF 后重新导入一次，确认没有丢材质。

## 最容易返工的三处

1. **比例阶段省事**：后期所有细节都建立在错误比例上。
2. **倒角宽度随手给**：不同部件倒角不一致，整体会像玩具。
3. **UV 最后才做**：改拓扑就要重展 UV，返工成本最高。

把这三处前置，硬表面管线的稳定性会好很多。
